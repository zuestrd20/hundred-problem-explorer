# 100 個值得探索的問題

公開網站：https://zuestrd20.github.io/hundred-problem-explorer/

繁體中文研究索引：搜尋、領域／對象／範圍／可行性篩選、本機收藏與最多三項比較，幫助挑選值得先驗證的小專案。

研究快照：2026-10-05。網站發布：2026-10-06。查核日期不因網站恢復或發布而重新標新。

## 資料原則

- 正好 100 筆，跨 8 領域，106 個不同公開來源網址。
- `evidence` 是來源支持的背景；`gap`、`mvp`、`test` 與可行性是研究者推論。
- 指南不等於盛行率或市場需求調查；國外情境不直接等於本地需求。
- 可行性依資料、串接、合作與安全審查需要判斷，沒有虛構市場分數。
- 原始來源的內容與權利歸各來源所有；本網站只提供必要的原創短摘要。
- 不提供醫療、法律或投資個案建議，不保證收益。

完整資料在 `data/problems.json`，網站可下載篩選結果 JSON 或 CSV。

## 隱私

沒有帳號、分析追蹤器、第三方字型或資料回傳。收藏只存 localStorage，比較清單只存頁面記憶體；清除網站資料會失去收藏。GitHub Pages 仍可能記錄技術請求，外部來源適用各自的隱私政策。

## 開發

Node.js 22 或以上：

```
npm test
npm start
```

原生 HTML/CSS/JS，無前端執行依賴。可選的 npm run test:dom 需要另行安裝 jsdom 開發依賴；基本 npm test 無依賴。GitHub Pages 使用 main 根目錄。具體測試結果見 VALIDATION.md。
